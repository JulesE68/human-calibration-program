# Human Calibration Program

Fourteen quick tests of human abilities: timing, rhythm, reflexes, color vision, memory, hearing and more. Each test scores you from 0 to 100%, and your average becomes an estimated age.

Press **Start calibration** to take 5 random tests and get your age.

Plain HTML, CSS and JavaScript in a single `index.html`. No build step and no dependencies. Fonts are bundled in `fonts/` (SIL Open Font License).
